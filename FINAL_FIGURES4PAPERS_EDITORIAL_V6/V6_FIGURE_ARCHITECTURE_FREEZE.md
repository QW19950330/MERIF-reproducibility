# MERIF five-market V6 figure architecture freeze

## Frozen scientific scope

- S1 is the principal setting. Main five-market S1 comparisons use `COMMON_MASK`, with `N = 15,311` per market.
- Cross-setting comparisons use `GLOBAL_COMMON`, with `N = 15,311` per market-setting cell.
- `S2_DA` is the only principal information extension. `S2_LEGACY` is sensitivity context; `S3` is always labelled ex-post.
- W60, all event thresholds, all fitted objects, all locked trajectory windows, and all 168-h/24-h bootstrap draws remain frozen.
- P95 XRM estimates for ES and FR each have one held-out event and are descriptive only.
- Positive values mean improvement by the proposed component in all transformed effect displays. Every sign inversion is recorded in value lineage.
